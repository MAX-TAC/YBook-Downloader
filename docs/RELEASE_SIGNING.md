# Release signing / Google Play

Текущий GitHub Actions собирает `debug` APK. Такой файл подходит для тестирования, но не является релизом для Google Play.

Для публикации нужно:

1. Создать аккаунт разработчика Google Play и приложение в Play Console.
2. Создать собственный **upload keystore** и хранить его приватно. Не добавлять `.jks` в публичный GitHub-репозиторий.
3. Добавить keystore и пароли в GitHub Actions Secrets.
4. Настроить Gradle `signingConfig` для release.
5. Собирать `bundleRelease` (`.aab`) и загружать его в Play Console.
6. Использовать Play App Signing: Google Play будет подписывать APK, доставляемые пользователям, своим app-signing key.
7. Если Android OAuth будет переведён на официальный Yandex LoginSDK, зарегистрировать в Yandex OAuth SHA-256 сертификатов, которыми реально подписываются устанавливаемые версии приложения.

Важно: обычная подпись APK не убирает системное предупреждение о разрешении установки из неизвестного источника при sideload с GitHub. Это предупреждение связано со способом установки, а не с отсутствием подписи. Для пользователей Google Play установка происходит через доверенный магазин.
