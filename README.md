# YBook Downloader

Android-приложение для загрузки текстовых книг из Яндекс Книг/Bookmate API и экспорта в EPUB, FB2, PDF и TXT.

## Возможности MVP

- получение ссылки через Android «Поделиться»;
- ручная вставка ссылки;
- авторизация через Яндекс;
- получение названия и обложки;
- загрузка EPUB;
- отправка EPUB через системное меню Android (например, в Amazon Kindle);
- сохранение в `Download/YBook Downloader`;
- конвертация в FB2, PDF и TXT.

## Сборка

Откройте проект в Android Studio и дождитесь синхронизации Gradle.

Либо используйте GitHub Actions: после push в `main` workflow `Android APK` автоматически собирает debug APK. APK доступен в разделе Actions → соответствующий запуск → Artifacts.
