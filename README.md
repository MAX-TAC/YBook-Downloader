# YBook Downloader

Android-приложение для сохранения электронных и аудиокниг, доступных пользователю в Яндекс Книгах.

> Используйте приложение только для контента, к которому у вашей учётной записи есть законный доступ. Проект не предназначен для обхода DRM или ограничений доступа.

## Версия 0.7.0

### Аудиокниги и выбор глав
- после выбора качества M4A приложение показывает список доступных глав;
- можно скачать только нужные главы либо выбрать сразу все;
- история хранит номера выбранных глав;
- повторные скачивания одной аудиокниги при **«Поделиться»** теперь объединяются в один пункт;
- если одна и та же глава скачивалась несколько раз, для отправки используется её самая свежая локальная копия;
- в меню «Поделиться» и истории показываются конкретные номера сохранённых глав, например `Главы: 1–3, 7, 10–12`.

### Главный экран
- переключатель **«Текст / Аудио»** перенесён ближе к кнопкам скачивания;
- поиск новой книги теперь открывается круглой плавающей кнопкой с иконкой **поиска** в правом нижнем углу;
- исходную ссылку можно брать как с текстовой, так и с аудиоверсии произведения.

### Скачивание
Для режима **«Текст»** доступны:
- EPUB;
- FB2;
- PDF;
- TXT.

Для режима **«Аудио»** доступны M4A-дорожки:
- обычное качество (`min_bit_rate`);
- максимальное качество (`max_bit_rate`).

Файлы сохраняются в `Загрузки/YBook Downloader/`.

### Поделиться
- приложение никогда не скачивает книгу повторно по кнопке **«Поделиться»**;
- доступны только уже сохранённые локальные файлы;
- текстовые форматы показываются отдельными пунктами;
- все сохранённые главы одной аудиокниги объединяются в один пункт M4A;
- после выбора открывается стандартное меню Android (Kindle, Telegram, Google Drive и другие приложения).

### Настройки
Доступны режимы оформления:
- **Как в системе**;
- **Светлая**;
- **Тёмная**.

Кнопка выхода переименована в **«Сбросить авторизацию Яндекс Книг»** и оформлена отдельной полноразмерной кнопкой. Кнопка «Готово» удалена — окно закрывается обычным нажатием вне него.

В нижней части настроек отображаются:
- иконка YBook Downloader;
- текущая версия приложения;
- ссылка **GitHub** на `MAX-TAC/YBook-Downloader`.

### Иконка приложения
Используется собственная синяя иконка со стрелкой загрузки, книгой и аудиоволной. Она подключена как adaptive icon.

## Поддерживаемые версии Android

Android 8.0+ (API 26).

На Android 10+ сохранение в Downloads выполняется через MediaStore без запроса полного доступа к файловой системе. На Android 8/9 приложение запрашивает `WRITE_EXTERNAL_STORAGE` только при сохранении.

## Сборка

GitHub Actions workflow в `.github/workflows/build.yml` автоматически собирает debug APK после push в ветку `main`.

Для публикации в Google Play потребуется release Android App Bundle (`.aab`) и постоянная release-подпись. Debug APK из Actions предназначен для тестирования.
