# YBook Downloader

Android-приложение для сохранения электронных и аудиокниг, доступных пользователю в Яндекс Книгах.

> Используйте приложение только для контента, к которому у вашей учётной записи есть законный доступ. Проект не предназначен для обхода DRM или ограничений доступа. Проект не связан с Яндексом и использует внутренний недокументированный API Bookmate/Яндекс Книг, поэтому отдельные функции могут перестать работать после изменений на стороне сервиса.

## Версия 0.8.0

### История произведений
История больше не показывает каждое отдельное скачивание как самостоятельную запись.

Для одного произведения создаётся одна карточка, в которой объединяются все сохранения:
- текстовые форматы: EPUB, FB2, PDF, TXT;
- все аудиоглавы, которые скачивались в разные моменты времени;
- дата последнего скачивания.

Например:

```text
Большая книга мифов России
Текст: EPUB, PDF
Аудио: главы 1–7, 10–12
Последнее скачивание: 06.09.2026 18:30
```

Нажатие на карточку истории снова открывает произведение на главном экране для повторного скачивания. Отдельная кнопка «Поделиться» из истории удалена.

### Избранное / библиотека Яндекс Книг
Добавлена вкладка **«Избранное»**. Она синхронизируется с личной библиотекой авторизованного аккаунта через `profile/library_cards`.

- загружаются сохранённые текстовые и аудиокниги;
- текстовая и аудиоверсия одного произведения объединяются в одну карточку;
- есть поиск по названию и автору;
- есть кнопка обновления;
- нажатие на карточку открывает произведение на главном экране, после чего можно выбрать «Текст» или «Аудио» и скачать нужный вариант.

### Настройки
- кнопка отключения аккаунта теперь заполненная и визуально выделенная;
- надпись изменена на **«Отключить аккаунт Яндекс Книг»**;
- из нижней части настроек убраны название и иконка приложения;
- оставлены только номер версии и текстовая ссылка на GitHub;
- отдельная иконка GitHub больше не используется.

Режимы оформления:
- **Как в системе**;
- **Светлая**;
- **Тёмная**.

### Аудиокниги
- выбор обычного или максимального качества M4A;
- выбор отдельных глав;
- «Выбрать все / Снять все»;
- несколько скачиваний одной аудиокниги объединяются при «Поделиться»;
- повторно скачанная глава заменяет предыдущую локальную ссылку при отправке.

### Текстовые форматы
- EPUB;
- FB2;
- PDF;
- TXT.

Файлы сохраняются в `Загрузки/YBook Downloader/`.

### Поделиться
Кнопка «Поделиться» не скачивает файлы повторно. Она работает только с уже сохранёнными локальными файлами и позволяет выбрать конкретный доступный формат.

## Поддерживаемые версии Android

Android 8.0+ (API 26).

На Android 10+ сохранение в Downloads выполняется через MediaStore без запроса полного доступа к файловой системе. На Android 8/9 приложение запрашивает `WRITE_EXTERNAL_STORAGE` только при сохранении.

## Сборка

GitHub Actions workflow в `.github/workflows/build.yml` автоматически собирает debug APK после push в ветку `main`.

Для публикации в Google Play потребуется release Android App Bundle (`.aab`) и постоянная release-подпись. Debug APK из Actions предназначен для тестирования.
