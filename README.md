# YBook Downloader

Android-приложение для поиска и сохранения электронных и аудиокниг, доступных пользователю в Яндекс Книгах.

> Используйте приложение только для контента, к которому у вашей учётной записи есть законный доступ. Проект не предназначен для обхода DRM или ограничений доступа. Проект не связан с Яндексом и использует внутренние недокументированные API Bookmate/Яндекс Книг, поэтому отдельные функции могут перестать работать после изменений на стороне сервиса.

## Версия 0.9.0

### Новая структура приложения
Нижняя навигация теперь состоит из четырёх разделов:

- **Главная** — актуальные подборки Яндекс Книг, популярные поисковые запросы и недавно скачанные произведения;
- **Поиск** — поиск по каталогу по названию книги или автору, а также отдельная кнопка **«По ссылке»**;
- **Избранное** — библиотека авторизованного аккаунта с постраничной подгрузкой;
- **История** — сгруппированная история произведений и всех сохранённых форматов.

### Главная
Приложение получает несколько актуальных редакционных разделов с публичной главной страницы `books.yandex.ru` и показывает их горизонтальными подборками. Если структура сайта изменится, поиск, избранное и история продолжат работать, а главная покажет доступные популярные запросы или сообщение о невозможности загрузить подборки.

Дополнительно выводятся:
- популярные поисковые запросы Bookmate/Яндекс Книг;
- недавно скачанные произведения из локальной истории.

### Поиск по каталогу
Поиск работает через GraphQL API Bookmate и поддерживает:
- название книги;
- автора;
- текстовые книги;
- аудиокниги;
- автоматическую подгрузку следующей страницы результатов;
- добавление и удаление произведения из библиотеки кнопкой с сердцем.

Кнопка **«По ссылке»** открывает прежнее окно ввода ссылки из приложения Яндекс Книги. Пустое поле показывает кнопку вставки из буфера, заполненное — кнопку полной очистки.

### Избранное: бесконечная прокрутка
Ранее приложение могло получить только первую серверную страницу библиотеки, из-за чего на больших аккаунтах отображалась лишь часть книг.

В 0.9.0 библиотека загружается небольшими страницами с `limit`/`offset`. Когда пользователь доходит до конца текущего списка, автоматически запрашивается следующая страница. Это рассчитано в том числе на библиотеки из сотен и тысяч произведений.

Также:
- текстовая и аудиоверсия одного произведения объединяются;
- есть поиск среди уже загруженной части списка;
- при поиске и достижении конца списка новые страницы продолжают подгружаться;
- произведение можно удалить из библиотеки через кнопку удаления с подтверждением;
- нажатие на карточку открывает произведение для скачивания.

### Скачивание
Текст:
- EPUB;
- FB2;
- PDF;
- TXT.

Аудио:
- M4A обычного качества;
- M4A максимального качества;
- выбор отдельных глав или всех глав.

Файлы сохраняются в `Загрузки/YBook Downloader/`.

### Поделиться
Кнопка «Поделиться» работает только с уже сохранёнными локальными файлами и не скачивает контент повторно. Для одной аудиокниги несколько отдельных загрузок глав объединяются в один набор сохранённых дорожек.

### Оформление
В настройках доступны:
- **Как в системе**;
- **Светлая**;
- **Тёмная**.

## Поддерживаемые версии Android

Android 8.0+ (API 26).

На Android 10+ сохранение в Downloads выполняется через MediaStore без запроса полного доступа к файловой системе. На Android 8/9 приложение запрашивает `WRITE_EXTERNAL_STORAGE` только при сохранении.

## Сборка

GitHub Actions workflow в `.github/workflows/build.yml` автоматически собирает debug APK после push в ветку `main`.

Для публикации в Google Play потребуется release Android App Bundle (`.aab`) и постоянная release-подпись. Debug APK из Actions предназначен для тестирования.
