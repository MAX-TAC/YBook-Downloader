# YBook Downloader

Android-приложение для сохранения электронных и аудиокниг, доступных пользователю в Яндекс Книгах.

> Используйте приложение только для контента, к которому у вашей учётной записи есть законный доступ. Проект не предназначен для обхода DRM или ограничений доступа.

## Версия 0.6.0

### Выбор глав аудиокниги
- после выбора качества M4A приложение получает список доступных дорожек;
- открывается отдельное окно **«Выберите главы»**;
- можно отметить отдельные главы;
- доступны быстрые действия **«Выбрать все» / «Снять все»**;
- отображается счётчик выбранных глав;
- если API возвращает название главы, оно показывается под её номером;
- скачиваются только отмеченные дорожки;
- история сохраняет количество загруженных глав, например `M4A • Максимальное качество • 7 из 24 глав`.

### Оформление
В **Настройки → Оформление** доступны три режима:
- **Как в системе**;
- **Светлая**;
- **Тёмная**.

Выбор сохраняется между запусками. На Android 12+ Material You Dynamic Colors продолжают использовать системную палитру, но светлый/тёмный режим можно зафиксировать независимо от системной темы.

### Иконка
Добавлена собственная адаптивная иконка YBook Downloader: красный фон, открытая книга, стрелка загрузки и небольшой аудиосимвол. Она не использует логотип или букву «Я» Яндекса.

### Единая карточка произведения
- можно вставить ссылку как на `https://books.yandex.ru/books/...`, так и на `https://books.yandex.ru/audiobooks/...`;
- приложение пытается найти парную текстовую/аудиоверсию того же произведения;
- над карточкой есть переключатель **«Текст / Аудио»**;
- если одной из версий нет, соответствующая кнопка недоступна.

### Скачивание
Для вкладки **«Текст»** доступны:
- EPUB;
- FB2;
- PDF;
- TXT.

Для вкладки **«Аудио»** доступны M4A-дорожки:
- обычное качество (`min_bit_rate`);
- максимальное качество (`max_bit_rate`).

Файлы сохраняются в `Загрузки/YBook Downloader/`.

### «Поделиться» без повторного скачивания
- кнопка **«Поделиться»** использует только уже сохранённые локальные файлы;
- пользователь выбирает нужный ранее скачанный формат;
- для частично скачанной аудиокниги передаются только сохранённые главы;
- после выбора открывается стандартное меню Android (Kindle, Telegram, Google Drive и т. д.).

### Поиск и история
- пустое поле ссылки показывает кнопку **«Вставить из буфера»**;
- заполненное поле автоматически показывает **«Очистить»**;
- после нахождения произведения поле ссылки исчезает;
- кнопка `+` открывает поиск новой книги;
- история хранит скачанные форматы и позволяет повторно ими поделиться.

## Поддерживаемые версии Android

Android 8.0+ (API 26).

На Android 10+ сохранение в Downloads выполняется через MediaStore без запроса полного доступа к файловой системе. На Android 8/9 приложение запрашивает `WRITE_EXTERNAL_STORAGE` только при сохранении.

## Сборка

GitHub Actions workflow в `.github/workflows/build.yml` автоматически собирает debug APK после push в ветку `main`.

Для публикации в Google Play потребуется отдельная release-сборка Android App Bundle (`.aab`) и постоянная подпись. Debug APK из Actions предназначен только для тестирования.

### Иконка приложения
В v0.6.0 используется новая собственная иконка YBook Downloader: знак загрузки с книгой и аудиоволной. Иконка подключена как adaptive icon, поэтому Android корректно применяет форму значка лаунчера устройства.
